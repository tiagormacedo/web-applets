# Web apps projects

Five small web apps: three built with vanilla HTML/CSS/JS and two built with Vue. Each app is self-contained in its folder.

| App | Description | Tech | Docs |
|-----|-------------|------|------|
| [Etch-a-Sketch](./etch-a-sketch/) | Draw on a pixel grid with your mouse | HTML, CSS, JS | [README](./etch-a-sketch/README.md) |
| [Moving eyes](./moving-eyes/) | Eyes that track the mouse cursor | HTML, CSS, JS | [README](./moving-eyes/README.md) |
| [Guess the number](./guess-the-number/) | Classic number-guessing game | HTML, CSS, JS | [README](./guess-the-number/README.md) |
| [Todo List](./todo-list/) | Simple task manager built with Vue | Vue | [README](./todo-list/README.md) |
| [Gastos Vocy](./gastos-vocy/) | Expenses tracking app built with Vue | Vue | [README](./gastos-vocy/README.md) |
